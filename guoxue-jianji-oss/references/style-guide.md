# 固定设定与视觉规格

## 一、人物与场景

| 角色 | 外观 | 服装 | 道具 |
| --- | --- | --- | --- |
| 老先生 | 银白须发、圆框眼镜、慈祥睿智 | 深青灰长衫马褂 | 线装古籍、毛笔、青瓷茶盏 |
| 命主 | 三十岁上下短发、好奇、略前倾 | 月白长衫 | 一张泛黄的纸（抄来的八字） |

- 场景：民国书斋，深色木纹，暖黄油灯，浅景深，体积光。
- 镜头分工：
  - `master.mp4` — 老先生单人半身，讲知识点时用。
  - `visitor.mp4` — 命主单人半身，追问时用。
  - `two.mp4` — 双人同框（中景），开场、收尾、感慨用。
- 三段素材均为 768×1152、约 5.2s、24fps、**自带音轨（合成时丢弃）**；合成统一 `scale=1080:1620` + `pad=1080:1920:0:150` 补黑边，不裁人物。
- 原始 AI 角标在左上角，合成时用 `delogo=x=6:y=6:w=150:h=54` 淡化；**抖音后台仍须勾选「内容由 AI 生成」声明**。

## 二、人脸框（Wav2Lip `--box`，顺序 y1 y2 x1 x2）

| 键 | 用途 | 坐标 |
| --- | --- | --- |
| `M` | master 里的老先生 | 390 575 210 370 |
| `V` | visitor 里的命主 | 370 625 390 555 |
| `T2M` | two 里的老先生（左） | 195 360 205 335 |
| `T2V` | two 里的命主（右） | 200 355 515 630 |

新增素材用 `python3 scripts/detect_face_box.py <video> [--two]` 重新测。

## 三、声音

| 角色 | 音色 | 语速 | 效果 |
| --- | --- | --- | --- |
| 老先生 | `zh-CN-YunjianNeural`（成熟稳重） | −8% | 娓娓道来，有分量 |
| 命主 | `zh-CN-YunxiNeural`（年轻清亮） | +2% | 青年好奇感 |

- 全部走 edge-tts（微软云，免费、无需密钥，需联网）。
- 备选音色（曾生成过对比样本）：云扬、云霞（男）；晓晓、晓伊（女，旁白可用）。
- 音量目标：mean −28dB / max −7dB 左右。

## 四、版式

- 画布 1080×1920，25fps，H.264 + yuv420p，AAC 128k 44.1kHz 立体声。
- 字幕条：底部 `(40, top)-(1040, 1840)`，圆角 20，底色 `rgba(10,14,20,232)`；左侧角色标签（老先生=金 `#F0CD82`，命主=青 `#A5E8DE`），台词 44px 米白 `#F0ECE1`，每行 ≤19 字、最多 4 行。
- 右上角标：`古籍情景演绎 · 非真人测算`，24px，灰 `rgba(178,182,188,230)`。
- 尾板：深底 `rgb(16,21,28)`，金框圆角卡片，金色 64px 标题两行 + 米白 42px 两行 + 36px 互动语 + 26px 免责两行；尾板时长 3.5s（纯静音）。

## 五、灵动思考弹窗

| 元素 | 参数 |
| --- | --- |
| 气泡 | 宽 872、圆角 34、底色由 `rgb(30,39,49)` 渐变到 `rgb(16,22,29)`、描边 `rgba(232,197,132,168)` 2px、顶部 130px 高光 |
| 光晕 | 双层高斯模糊（18px 暖白 + 44px 琥珀），强度随时间呼吸 96→130 |
| 入场 | 0.70s easeOutBack(1.45)：缩放 0.64→1.0、旋转 −4.2°→0°、淡入 0.30s |
| 浮动 | 正弦 ±3.4px，周期约 3.1s |
| 思考点 | 左上三点，等首个知识点出现前上下跳动（幅度 6.5px），之后转为缓慢呼吸 |
| 尾巴 | 左下三个递减小圆点（r=13/9.5/7），依次脉冲，alpha 150–245 |
| 知识点行 | 0.42s easeOutBack(2.6)：缩放 0.82→1.0、淡入 0.14s、横向扫光（高斯带，强度 42，0.62s） |
| 落定反馈 | 行出现瞬间，整块气泡做 1.6% 衰减回弹 |
| 分隔线 | 2px，正弦渐变两端淡出（alpha 峰值 215） |

字体统一 `STHeiti Medium.ttc`（macOS 自带）。
